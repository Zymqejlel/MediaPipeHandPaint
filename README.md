# MediaPipe Hand Paint 手势绘画程序
## 项目简介
基于MediaPipe手部关键点检测 + OpenCV实现的实时手势交互绘画程序，通过摄像头识别手势完成绘制、清空、退出操作，计算机动画课程作业。

## 手势交互规则
1. **绘制线条：单独伸出食指**
仅食指抬起，中指、无名指、小指弯曲，移动食指，跟随指尖绘制紫色线条。
2. **清空画布：五指握拳**
所有手指弯曲握紧，画布上全部线条清空。
3. **手势退出：OK手势（带防抖防误触）**
拇指指尖贴住食指指尖，**中指、无名指、小指三根手指伸直张开**；
需要连续稳定识别5帧该手势，才会触发退出，过滤一闪而过的误识别。
4. **兜底退出**
鼠标点击摄像头窗口，按下键盘 `ESC`；或者点击窗口右上角关闭按钮。
